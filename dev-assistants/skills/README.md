# Skills and workflows

Planned definitions (task DEV-03). Each will be trialled once on a real task before it is considered done.

| Skill | Responsibility |
|---|---|
| `requirement-analysis` | Turn a requirement into development tasks, architecture changes and required resources |
| `provisioning-prep` | Prepare compute, database and cache configuration for human approval |
| `code-generation` | Assist with endpoints, models, configuration, scripts and tests |
| `test-and-validate` | Run the project tests and report results |
| `troubleshooting` | Analyse approved logs and failures |
| `deployment` | Validate configuration and prepare deployment commands |

These are project-specific workflows, not prebuilt products of any vendor.
